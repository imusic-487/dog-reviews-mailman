# The Dog Reviews the Mailman

One funny one-line review a dog gives the mailman, written by `main.py` to `/output/entry.txt`.

> One star. He comes every single day, stuffs paper through my slot, and has never once brought me a treat — so I bark. That is the review.

Built for the make.fun bounty [The Dog Reviews the Mailman](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85).
